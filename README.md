# Nom de l'aplicació 
Editor d'imatges

## Autor/a
Luis Miguel Garcia

## Descripció
L'aplicació és un editor d'imatges amb IA  enfocada sobretot en treure elements de la fotografia i omplir-ne el vuit que hi deixa sense que es noti.

## Versions utilitzades
Angular CLI       : 22.1.8
Node.js           : 24.21.0
Package Manager   : npm 11.19.0
git version 2.52.0.windows.1

## Com crear i executar el projecte
Dependencies: npm install
Creació projecte: ng new ioc-angular-editor-imatges-luismiguel-garcia --routing=true --style=scss --ssr=false --standalone=true --file-name-style-guide=2016 --skip-git=true --package-manager=npm
Executar: ng serve
